# Verification

Statistical verification of every distractor and anchor claim. Implements `validator.md` §5.

## Layout

```
verification/
  runs/                  # raw runs of the baseline agent (gitignored body, manifests checked in)
    T-XXX/
      D-3/
        W/run-01.jsonl, run-02.jsonl, ...   # 30 runs on workspace W
        Wp/run-01.jsonl, run-02.jsonl, ...  # 30 runs on workspace W' (ablated)
  reports/               # per-claim Fisher's-exact reports
    T-XXX/
      D-3.yaml           # see schema in validator.md \u00a75.6
  coverage.md            # generated by tools/coverage_matrix.py
```

## Statistical procedure

For each claim:
1. Run baseline agent N=30 times on W and N=30 times on W'.
2. One-sided Fisher's exact test, alpha=0.05.
3. Odds ratio with Haldane-Anscombe 0.5 correction.
4. Verified iff p < 0.05 in the correct direction AND OR >= 3.

See `tools/stats.py` for the helper.
