# Generator Pools

These JSON files hold reusable synthetic-data pools for the Meridian Trust small-bank slice.

The default generator is calibrated for a small regional bank:

- 12 branches across NC, SC, GA, and FL
- roughly 6 employees per branch at scale 1
- 5 core departments
- compact retail banking, operations, marketing, HR, finance, payroll, benefits, and incident surfaces

Keep pools realistic and internally consistent. IDs and labels here are reused across generated tables.
