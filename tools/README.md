# Tools

Utility scripts.

| Script                  | Purpose                                                                                  |
| ----------------------- | ---------------------------------------------------------------------------------------- |
| `coverage_matrix.py`    | Reads `tasks/*.yaml` + `verification/reports/**` and writes `verification/coverage.md`. |
| `stats.py`              | One-sided Fisher's exact + odds ratio with Haldane–Anscombe correction.                  |
| `validate_task_specs.py`| Validates every `tasks/*.yaml` against the schema in `validator.md` §7.                  |
